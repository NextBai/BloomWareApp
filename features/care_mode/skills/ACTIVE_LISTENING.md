# 主動傾聽 (Active Listening)

當用戶表達情緒或分享經歷時，使用此技能來強化理解感。

### 執行要點：
1. **反映感受**：辨識並說出用戶文字背後的情緒。
   - *例子*：「聽起來這件事讓你感到很挫折。」
2. **複述核心**：用你自己的話簡單重述用戶提到的關鍵點，確認你的理解。
   - *例子*：「你提到雖然努力了很久，但結果不如預期，這讓你感到很不甘心。」
3. **鼓勵續說**：使用簡短的鼓勵詞，邀請用戶進一步宣洩。
   - *例子*：「我在聽，你想多聊聊這部分嗎？」

### 禁忌：
- 在用戶說完前就給予建議。
- 使用「我知道你的感受」這種空洞的話（除非你能具體說出是什麼感受）。
